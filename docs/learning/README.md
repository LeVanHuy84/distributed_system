# Learning Notes & Interview Preparation

Mỗi tài liệu trả lời 7 câu hỏi vàng:
1. Bài toán gốc là gì?
2. Cơ chế tầng dưới hoạt động ra sao?
3. Các giải pháp đã cân nhắc?
4. Vì sao chọn giải pháp hiện tại (kèm trade-offs)?
5. Lỗi khó nhất đã gặp và cách điều tra?
6. Kết quả benchmark chứng minh điều gì?
7. Nếu làm lại trên hệ thống lớn hơn, sẽ thay đổi điểm nào?
